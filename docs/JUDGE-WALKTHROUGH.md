# Judge walkthrough

Review the evidence without a wallet. To repeat live payments, use an Arc testnet wallet with USDC; the smallest shield deposit is 1 USDC plus gas.

## 1. See the proof (30 seconds)

Open [`docs/E2E-TESTNET.md`](E2E-TESTNET.md). It is generated by `scripts/e2e-testnet.ts` against the public Arc testnet RPC (chain 5042002); every hash links to explorer.testnet.arc.io:

1. **Shield**: Alice approves and deposits 1 USDC into the `USDC-1` pool (twice; the second note is kept for the browser check).
2. **Send**: Alice pays Bob 0.1 USDC in one `StealthPay.sendToken` transaction. The USDC lands on a one-time address.
3. **Receive**: Bob scans the announcer through the public RPC, finds exactly his announcement, derives the stealth key and the script asserts that the key controls the address.
4. **Withdraw, gasless**: a real UltraHonk proof is generated, the relayer quotes its USDC fee, simulates and submits, and a fresh address that started with 0 USDC receives the note minus the fee. The script asserts the recipient never sent a transaction and that replaying the proof is refused.
5. **Browser**: section 7 of that file records the app doing Receive, Send and a withdrawal proved in a web worker (12 s) on the same deployment.

The earlier fork run, with the native-USDC/18-decimal assertions and a stealth address spending USDC as gas, is in [`docs/E2E-FORK.md`](E2E-FORK.md) (fork hashes have no explorer page).

## 2. Run it yourself (2 minutes)

```bash
pnpm install
"<arcfoundry>/anvil" --network arc --fork-url https://rpc.testnet.arc.io --port 9200 &
ARC_RPC_URL=http://127.0.0.1:9200 node scripts/e2e-fork.ts     # about 10 s; prints each step and writes docs/E2E-FORK.md
pnpm contracts:test                                            # 30 Foundry tests; real proofs verified on-chain
# the live testnet loop (spends about 2.6 USDC from DEPLOYER_ENV_FILE into fresh keys under .run/):
node scripts/e2e-testnet.ts
```

## 3. Where to look in the code

- `packages/contracts/src/privacy/KakushiPool.sol`: USDC-only pool, no owner, immutable cap; the 9 public inputs bind root, nullifier, recipient, relayer, fee, chain id and pool.
- `packages/contracts/test/privacy/KakushiPool.t.sol`: `test_ProofIsBoundToRootRecipientRelayerFeeChainAndPool` tampers with each input of one real proof in turn; `test_BlocklistedRecipientKeepsTheNoteSpendable` covers Circle's blocklist.
- `packages/relayer/src/relayer.ts`: fee in 6-decimal USDC units from 18-decimal gas cost, refusal when fee < gas.
- `packages/zk/circuits/shielded_withdraw/src/main.nr` and `pnpm zk:verifier --check`: the checked-in Solidity verifier is regenerated from the circuit and diffed.
- `scripts/deploy.sh`: `testnet|mainnet`, `CONFIRM_MAINNET=yes`, key from a file, deployer lock, chain-id check.

## 4. The app (optional)

```bash
pnpm --filter @kakushi/app build
pnpm --filter @kakushi/app start       # http://localhost:9210, reads the live testnet deployment
# gasless withdrawals also need a relayer: RELAYER_KEY_FILE=<file with a funded test key> RELAYER_PORT=9202 node packages/relayer/src/main.ts
#   then start the app with KAKUSHI_RELAYER_URL=http://127.0.0.1:9202
```

Pages: `/` landing, `/send`, `/receive`, `/shield` (deposit and withdraw), `/developers` (typechecked SDK/widget setup and contract links); the real 0.01 USDC widget is on `/`. Without `KAKUSHI_DEPLOYMENT_FILE` it reads `deployments/arc-testnet.json` (the live deployment). Every page loads with an empty wallet; the withdraw tab needs no wallet when a relayer is configured (`KAKUSHI_RELAYER_URL`), and proves in a web worker. Screenshots: `docs/screens/testnet/`.

## What is not claimed

Not audited; testnet only; pools are small and capped and their anonymity sets are small (only our own test deposits recorded); the relayer is a single operator; the FHE side of the original is not shipped; the circuit and verifier are reused from the earlier Monad project. See the README's "Honest limits".
