# Judge walkthrough

Five minutes, no wallet or funds needed. Everything below is reproducible from this repo.

## 1. See the proof (30 seconds)

Open [`docs/E2E-FORK.md`](E2E-FORK.md). It is generated by `scripts/e2e-fork.ts` against an Arc Foundry fork of Arc testnet (chain 5042002) and lists every transaction hash, its gas and its cost in USDC, in this order:

1. **Shield**: Alice approves and deposits 10 USDC into the `USDC-10` pool.
2. **Send**: Alice pays Bob 25 USDC in one `StealthPay.sendToken` transaction. The USDC lands on a one-time address.
3. **Receive**: Bob scans, finds exactly one announcement addressed to him, derives the stealth key, and the script asserts that the key controls the address and that its native balance equals its ERC-20 balance times 1e12 (Arc's two views of one USDC balance). Bob then shields 10 USDC *from that address*; it holds only USDC and pays gas in USDC.
4. **Withdraw, gasless**: for each note a real UltraHonk proof is generated, the relayer quotes its USDC fee, simulates and submits, and a fresh address that started with 0 USDC receives the note minus the fee. The script asserts the recipient never sent a transaction, the relayer net-gained USDC, and that replaying the proof is refused.

Hashes come from a fork, so there is no public explorer page for them; the fork runs Arc's actual USDC contract at `0x3600…0000`.

## 2. Run it yourself (2 minutes)

```bash
pnpm install
"<arcfoundry>/anvil" --network arc --fork-url https://rpc.testnet.arc.io --port 9200 &
ARC_RPC_URL=http://127.0.0.1:9200 node scripts/e2e-fork.ts     # about 10 s; prints each step and writes docs/E2E-FORK.md
pnpm contracts:test                                            # 30 Foundry tests; real proofs verified on-chain
```

## 3. Where to look in the code

- `packages/contracts/src/privacy/KakushiPool.sol`: USDC-only pool, no owner, immutable cap; the 9 public inputs bind root, nullifier, recipient, relayer, fee, chain id and pool.
- `packages/contracts/test/privacy/KakushiPool.t.sol`: `test_ProofIsBoundToRootRecipientRelayerFeeChainAndPool` tampers with each input of one real proof in turn; `test_BlocklistedRecipientKeepsTheNoteSpendable` covers Circle's blocklist.
- `packages/relayer/src/relayer.ts`: fee in 6-decimal USDC units from 18-decimal gas cost, refusal when fee < gas.
- `packages/zk/circuits/shielded_withdraw/src/main.nr` and `pnpm zk:verifier --check`: the checked-in Solidity verifier is regenerated from the circuit and diffed.
- `scripts/deploy.sh`: `testnet|mainnet`, `CONFIRM_MAINNET=yes`, key from a file, deployer lock, chain-id check.

## 4. The app (optional)

```bash
pnpm --filter @kakushi/app build
KAKUSHI_DEPLOYMENT_FILE=deployments/arc-testnet.fork.json ARC_RPC_URL=http://127.0.0.1:9200 pnpm --filter @kakushi/app start   # http://localhost:9210
```

Pages: `/` landing, `/send`, `/receive`, `/shield` (deposit and withdraw), `/developers` (the `<KakushiPay>` widget demo). With an injected wallet pointed at the fork the same flows run in the browser; the withdraw tab proves in a web worker. I have loaded every page with an empty wallet; I have not driven a wallet through the browser flow.

## What is not claimed

Not audited; not on a public network yet; pools are small and capped, so anonymity sets start small; the relayer is a single operator. See the README's "Honest limits".
